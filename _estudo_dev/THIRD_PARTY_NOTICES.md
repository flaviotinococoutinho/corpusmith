# Third-party notices

A versão 1.0 não incorpora bibliotecas de execução, fontes remotas, ícones ou assets de terceiros. Usa HTML, CSS, JavaScript clássico e SVG nativos.

Referências catalogadas não são distribuídas como dependências. Se uma biblioteca for vendorizada no futuro, registre nome, versão, licença, identificador pesquisável e hash. Nenhum CDN é permitido.
